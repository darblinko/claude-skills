Problem

Two failures that pass without an error message. Chrome's print engine clips anything that overflows the page box instead of continuing it on the next page, so a mermaid diagram taller than one page loses its lower part. In a time-series dataset, a feature built with groupby(bucket).transform("last") gives every bar the bucket's final value, so on 1-minute bars in 5-minute buckets 4 of every 5 bars read a close recorded after them.

The 4 of 5 figure is asserted in tests/test_lookahead_patterns.py and plotted below from docs/data.json. The tall-diagram case is skills/markdown-to-pdf/test/fixtures/tall.md.

How it works

Claude Code reads only each skill's name and description until a request matches, then loads the full SKILL.md. The PDF skill runs a script; the other two are instructions with code patterns. The renderer pipeline:

flowchart TD
  md[Markdown file] --> extract[Extract mermaid fences]
  extract --> html[markdown-it to HTML]
  html --> chrome[Chromium at printed width]
  chrome --> render[mermaid to SVG]
  render --> fit{Fits the page?}
  fit -- yes --> scale[Scale to fit]
  fit -- too tall --> slice[Slice across pages]
  fit -- far too wide --> band[Stacked bands]
  scale --> pdf[PDF with header and footer]
  slice --> pdf
  band --> pdf

Thresholds: LEGIBLE_SCALE, TARGET_SCALE and MAX_BANDS in skills/markdown-to-pdf/md2pdf.js.

Measured results

The look-ahead skill's Python blocks, executed as written from its SKILL.md on synthetic random-walk bars. First, which bucket patterns read a later close under three bar conditions; then the correlation audit on a dataset with two planted leaks.

Reproduce: uv run python examples/lookahead_demo.py writes docs/data.json.

Run it

  1. git clone https://github.com/darblinko/claude-skills
cp -r claude-skills/skills/markdown-to-pdf ~/.claude/skills/
  2. cd claude-skills
uv sync && uv run pytest -q
  3. cd skills/markdown-to-pdf
npm ci && npx playwright-core install chromium && npm test

Limitations

  • The original daily-merge fix in the look-ahead skill shifted the date key with the values and removed no look-ahead. It is fixed, and a test keeps the original pattern as a negative case.
  • The row-count bucket shift is leak-free only for bars of 1 minute or longer; on 30-second bars it reads later closes (chart above). The gap-safe variant does not.
  • The look-ahead measurements use synthetic data and say nothing about effect size on a real model.
  • ec2-ml-training ships no scripts; nothing in the repository runs its interface.
  • The PDF tests check structure, not visual layout. A narrow, tall diagram is scaled up to the column width before slicing and can span many pages.
